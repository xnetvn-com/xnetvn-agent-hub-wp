## Version-bound compatibility

The installed wp-env still imports simple-git as a CommonJS callable. Version4 provides the named `simpleGit` export, so a direct security override alone fails before cloning. The compatibility test reproduced that TypeError before correction.

`bin/prepare-wp-env.cjs` changes only the two reviewed wp-env import statements to the named export. It requires the exact wp-env version, project-local nonsymlink directory/files, and SHA-256 of either the original published file or exactly its reviewed patched form. Both files are validated before either write; repeated invocation verifies the existing patched bytes. Any upstream or unexpected modification fails rather than silently accepting a different dependency. The patch does not disable or alter simple-git's unsafe-operation protections.

Normal `npm ci` invokes the project's postinstall preparation. When scripts are intentionally disabled, run `npm run tooling:prepare` before using wp-env. `npm run test:tooling` also prepares dependencies, then tests YAML dump/load plus the Git APIs wp-env uses: clone with options, cwd, checkIsRepo, fetch, checkout, reset and sparse-checkout/raw. Both native and library Git calls use the same minimal environment, omit caller home/config/template/editor/repository overrides, and disable system configuration with a fixed flag. The library allowlists only that fixed flag; unsafe operation allowances stay disabled. An inherited-GIT override regression also passed. Its repositories are fresh disposable local fixtures; it starts no containers/database/browser, contacts no remote Git server and changes no project/reference repository history. CI's audit job runs the contract before auditing.

These API checks complement the hosted wp-env integration matrix. The replacement graph is not accepted as hosted-compatible until the new required CI jobs actually finish. Future wp-env upgrades require reviewing or removing the exact compatibility patch, updating the lockfile and repeating both contract and hosted checks. Do not relax audit severity or suppress advisories to get a green result.
