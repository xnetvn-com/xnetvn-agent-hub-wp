## 🌟 Release Summary

Version **v0.1.0** is the initial Pre-release Foundation of xNetVN Agent Hub for WordPress. This release completes the entire core software architecture (Core Kernel), per-website persistence model, security protocol and fine-grained intersected authorization, together with a set of 5 System Pack Abilities through the official WordPress MCP Adapter.

---

## 🚀 Implemented Capabilities

### 1. Kernel and Service Providers
- Bootstrap in a deterministic order through `Plugin::boot()`.
- Fire the single `xnetvn_agent_hub_wp_loaded` event when initialization completes.
- Safely fail closed on PHP 8.2 and WordPress 6.9 environment checks, with clear error notices.

### 2. User-Owned API Keys and Cryptography
- Keys in `xnv_<key_id>_<secret>` format, 60 characters long (12-character Base32 Key ID, 32-byte Base64URL Secret).
- One-way hashing with `HMAC-SHA256` and an independent 32-byte Pepper per site (`autoload = 'no'`).
- Timing-safe `hash_equals()` comparisons and Dummy HMAC protection against Timing Attacks.
- Atomic key rotation using MySQL InnoDB transactions and `SELECT ... FOR UPDATE` row locks.

### 3. Guards and Transport Separation
- MCP route `/wp-json/xnetvn-agent-hub-wp/mcp` accepts Bearer Tokens only and rejects all Cookies.
- Management route `/wp-json/xnetvn-agent-hub-wp/v1/*` accepts session Cookies + `wp_rest` nonce only.
- Require HTTPS/TLS in real environments; strictly validate the `Origin` header.
- Sliding rate limits: 120 requests/minute/key and 10 failed attempts/minute/IP.

### 4. Core System Pack Abilities
1. `xnetvn/get-session-info`: Get session information, permissions, key scope, and remaining quota.
2. `xnetvn/get-site-info`: Get website information and the WordPress version.
3. `xnetvn/discover-abilities`: Discover the catalog of tools permitted by current permissions.
4. `xnetvn/get-ability-info`: Get the detailed JSON Schema of a specific tool.
5. `xnetvn/execute-ability`: Delegate permitted tool execution with a strict schema.

### 5. Audit, Privacy, and Management Interface
- Write asynchronous batch audit logs at the `shutdown` hook (without secrets or parameter values).
- Integrate personal data Export and Erasure tools according to the WordPress GDPR standard.
- User Profile interface and 6 management pages meet international accessibility standard **WCAG 2.2 Level AA**.
